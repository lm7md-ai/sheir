## ٢. ما تم إنجازه بالكامل في المرحلة الأولى (Completed Deliverables)

### أ. منظومة التصميم الفاخرة (Manuscript Design System)
- [x] سمات الألوان الثلاثية المعتمدة: "حبر منتصف الليل" (Midnight Ink #0B0D10)، "الرقّ العتيق" (Parchment #F6EFE0)، و"السبيا" (Sepia #1C1815).
- [x] حزم الخطوط العربية الأصيلة (Amiri, Aref Ruqaa, Cairo) مع حظر قاطع لتمديد الحروف (`letterSpacing: null`)، وارتفاع سطور مريح للحركات (1.9-2.4).
- [x] عائلة أيقونات مستديرة متجانسة (`Icons.*_rounded`) مع قصر الزخارف المخطوطية المخصصة على اللحظات البصرية الفاخرة (الروزيتا، الشموس، الخرطوشة).
- [x] معرض التصميم التفاعلي الداخلي في Flutter (`GalleryScreen`) والمعاينة الحية.
- [x] إشارات التسميع الثنائية المرمزة (لون + نمط خطي للمطابقة مع معايير الوصول الشامل WCAG AA):
  - **سليم (Correct)**: أخضر + خط سفلي متصل.
  - **خطأ / لحن (Wrong)**: قرمزي + خط مموج تحتي.
  - **تردد (Hesitation)**: عنبري + خط منقط تحتي.
  - **محذوف (Missing)**: رمادي + خط شطب في الوسط.
  - **زائد (Extra)**: بنفسجي + تسطير محدد ملون.

### ب. محركات اللغة والعروض والتكرار المتباعد (Pure Dart Core Engines)
- [x] محرك تسوية النصوص وحظر اللحن (`ArabicNormalizer`): إزالة التشكيل، توحيد الهمزات والألف المقصورة والتنوين مع خيارات دقيقة لنسب التسامح.
- [x] محرك البحور والأوزان الشعرية (`ArudEngine`): كشف التفاعيل، المقاطع الصوتية (أسباب وأوتاد)، وبحور الخليل الستة عشر مع حساب نسبة الملاءمة العروضية.
- [x] محرك المحاذاة الصوتية والتسميع المباشر (`RecitationAlignmentEngine`): خوارزمية Needleman-Wunsch للمقارنة اللفظية ورصد التردد، الإسقاط، والحشو بنسبة دقة مئوية وحساب درجات الإتقان.
- [x] محرك التكرار المتباعد الخوارزمي (`SpacedRepetitionEngine`): يدعم FSRS و SM-2 مع استقرار الذاكرة وتوقع فترات المراجعة للخيارات الأربعة (أعد، صعب، جيد، سهل).

### ج. البنية التحتية للبيانات والمرونة (Data Architecture & Resilience)
- [x] الفصل التام بين قاعدة بيانات الشعر المقروءة فقط (`poems.db` بجدول `verses_fts` بتقنية FTS5) وقاعدة بيانات المستخدم وتقدمه وسجلاته (`user_data.db`).
- [x] مستودع الاستعلام الصفحي (`PagedPoemRepository`) مع التمرير السلس بمعدل 120 إطاراً في الثانية.
- [x] اختبار إجهاد 100,000 بيت شعري (`stress_test_100k.py`) أثبت زمن استجابة استعلامي يبلغ **0.22 مللي ثانية** فقط، وهو متفوق بمراحل على ميزانية الـ 15ms.
- [x] فاحص السعة التخزينية (`DiskSpaceChecker`): منع استنزاف الذاكرة وانهيار التطبيق قبل بدء التنزيل للنماذج والأشعار.
- [x] أداة التنزيل القابلة للاستئناف (`ResumableDownloader`): دعم ترويسة `Range` في HTTP، وإعادة المحاولة التلقائية 3 مرات بتراجع أسي (Exponential Backoff)، ودفق التقدم.

### د. تجربة المستخدم والسجلات وحاجز الأخطاء (UX, Logging & Error Boundary)
- [x] إطار تسجيل الأحداث الحي (`DiwanLogger`): ذاكرة دائرية لسجلات التطبيق مع تصنيفات باللغة العربية، وأداة تصفية، ونسخ فوري للحافظة.
- [x] حاجز الأخطاء العالمي في فلاتر (`DiwanErrorBoundary`): واجهة مخطوطية راقية عند حدوث انهيار برمجي، مع تفاصيل تشخيصية وزر إعادة محاولة وخيار نسخ التقرير.
- [x] شاشة الإعدادات الشاملة (`SettingsScreen`): تغطي كافة الخيارات الـ 14 المطلوبة بدقة (السمات، الخطوط، أحجام النصوص، دقة التشكيل، حساسية التردد، أهداف الحفظ، النسخ الاحتياطي، إدارة النماذج، السجلات، وحول التطبيق).
- [x] شاشة السجلات التفاعلية (`LogsScreen`) متصلة بقائمة التطبيق ومركز الإعدادات.

### هـ. القنوات الأصلية والأتمتة المستمرة (Native Channels & CI/CD)
- [x] قناة أندرويد الأصلية لاستخلاص ومعالجة الصوت (`AudioExtractionChannel`) باستخدام Kotlin الحديث و `MediaExtractor` و `MediaCodec`، متجنبة حزم FFmpeg المهجورة.
- [x] خط سير GitHub Actions الآلي (`.github/workflows/ci.yml`) لفحص الكود والتحليل الثابت، وبناء واختبار تطبيق Flutter لنظام Android مع توقيع الـ APK.
