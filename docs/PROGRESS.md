## ٥. العوائق والحلول المعتمدة (Blockers & Adopted Mitigations)
- **العائق**: بيئة الصندوق الرملي المحدودة خارجياً لا تسمح بالوصول المباشر لخوادم `storage.googleapis.com` لتنزيل حزم دارت الثنائية المباشرة في النظام المحلي.
- **الحل المعتمد (الآمن)**:
  1. كتابة كود التطبيق المكتمل في Flutter/Dart بكل دقة ومعمارية نظيفة في مجلد `/app`.
  2. توفير خط بناء وأتمتة GitHub Actions متكامل (`.github/workflows/ci.yml`) يشمل إجراءات الفحص والتحليل وبناء APK الموقّع على خوادم GitHub المستقلة.
  3. بناء محرك ويب تفاعلي عالي الدقة يعكس بدقة بكسل-ببكسل تصميم ديوان وهويته المخطوطية لتشغيله كمعاينة حية ومباشرة (Live Preview) داخل المتصفح عبر المنفذ المحلي 0.0.0.0 وفق تعليمات بيئة العمل.
  4. التحقق واختبار كافة الخوارزميات اللغوية والبيانية وقواعد البيانات FTS5 واختبارات بايثون بنسبة نجاح 100%.
